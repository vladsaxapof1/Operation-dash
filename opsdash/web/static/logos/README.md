# Логотипы подключений

Плашки для каталога «Подключения»: `<id>.svg` или `<id>.png`, где `id` — из `opsdash/connectors.yaml`. Нет файла —
каталог рисует плашку с буквами (`mono`) цвета `color`. Товарные знаки принадлежат их владельцам.

| Файл | Откуда |
|---|---|
| `telegram.svg`, `bot.svg`, `gmail.svg`, `google_calendar.svg`, `claude.svg` | значки [simple-icons](https://simpleicons.org) 16.30.0 (CC0), белым на плашке цвета бренда оттуда же |
| `mail.svg` | конверт Яндекс Почты из присланного SVG — на белой плашке |
| `pachca.svg` | значок из присланного логотипа Пачки (без надписи) — на белой плашке |
| `chatgpt.svg` | узел из присланного логотипа ChatGPT — на скруглённой плашке того же цвета |
| `kaiten.png` | присланная картинка 900×900, уменьшена до 128×128 |
| `ymessenger.png` | встроенное превью присланного EPS Я.Мессенджера, углы прозрачные, 128×128 |
| `calendar.svg` | перерисован по превью присланного EPS Яндекс Календаря: в архиве только EPS / AI / CDR без векторного содержимого, которое можно открыть без Illustrator |

Лучше заменить `ymessenger.png` и `calendar.svg` на официальные SVG, когда они будут: файл с тем же именем
подхватится сам.

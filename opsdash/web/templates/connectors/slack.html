  1. Откройте api.slack.com/apps → Create New App → From a manifest → выберите своё рабочее пространство.
  2. Вставьте манифест ниже целиком (вкладка JSON) → Next → Create. 
    {{ slack_manifest }}
  3. Install to Workspace → Allow. Если приложения в вашем Slack ставит администратор, он получит запрос и одобрит установку.
  4. OAuth & Permissions → скопируйте User OAuth Token (начинается с xoxp-) и вставьте сюда.
{{ enabled_box('slack', 'Читать Slack') }} {{ secret_input('token', 'SLACK_TOKEN', 'xoxp-…') }}
Приложение — только ваше и только на чтение: в манифесте нет прав писать сообщения. Право search:read нужно, чтобы видеть упоминания вас в каналах, которые PULSE целиком не читает.

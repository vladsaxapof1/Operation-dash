# Бриф к встрече

Директор открывает бриф за несколько минут до встречи: за минуту понять, о чём встреча, что было
в прошлый раз, кто что должен и о чём спросить. Бриф можно скопировать и отправить участникам как повестку.

## Шаги — для каждой встречи из списка

1. `./ops briefs context <uid>` — встреча, участники, прошлые встречи (серия или похожее название),
   открытые задачи с участниками, решения из базы знаний, документы по названию и **путь файла для брифа**.
2. **Определи тему** по названию, описанию и участникам. Не ясно, о чём встреча (общее название
   вроде «Созвон», «Встреча», нет описания, участники ни о чём не говорят, прошлых встреч нет) —
   не выдумывай: `./ops briefs skip <uid> --why "<почему не ясно, коротко>"` и переходи к следующей.
   Если директор сама попросила бриф к этой встрече — собери то, что есть, и честно напиши, чего не хватает.
3. **Собери факты** (по одной команде, без конвейеров; не больше 8 команд на встречу):
   - прошлые встречи: Read `data/meetings/<id>/summary.md` — решения, договорённости, открытые вопросы;
   - задачи: `./ops commitments list --person "<имя>"` для 1–3 ключевых участников;
   - Kaiten: `./ops kaiten cards --who "<имя>"` или `--search "<тема>"`, если тема — проект;
   - решения: `./ops kb search "<тема>"`; документы: `./ops docs search "<тема>"`, затем
     `./ops docs show "<файл>" --part "…"` — свежие цифры (прогноз, план, отклонения).
4. **Напиши бриф** Write-ом в файл из шага 1 (`data/briefs/…md`) по шаблону ниже и сохрани:
   `./ops briefs set <uid> --file data/briefs/<…>.md --topic "<тема одной строкой>"`.

## Шаблон

```markdown
**Тема:** … · **Цель:** что нужно получить от встречи (решение, цифры, договорённость)

## В прошлый раз
- ДД.ММ «Название»: решили … ; договорились … (кто, срок)

## Открытые задачи
- Пётр → вам: … — до ДД.ММ (просрочено / в срок)
- Вы → Ольге: … — до ДД.ММ

## Цифры и материалы
- … (файл «…», лист/слайд) — только то, что пригодится на этой встрече

## Вопросы к встрече
1. …
2. …
```

- Для **встречи один на один** это повестка: взаимные задачи, просрочки, темы из переписки с человеком
  с прошлой встречи (`./ops messages search "<имя>" --days 14`), вопросы к нему.
- Пустые разделы удаляй. Коротко: 10–25 строк. Факты — с датой и источником; нет данных — так и пиши.
- Решения из базы знаний — опора: не противоречь им.
- Имена — как в справочнике людей; директора называй «вы». Внутренние номера (`commitment 12`) не пиши.
- Личные (нерабочие) переписки не пересказывай.

# Итоги недели

1. `./ops week` (или `./ops week --date ГГГГ-ММ-ДД`, если в задании названа дата) — встречи с длительностью,
   разобранные записи, задачи (новые, закрытые, просроченные), загрузка, решения, подтверждения,
   следующая неделя.
2. Если нужно — уточни: `./ops commitments list --overdue`, `./ops kb list --days 7`, summary.md ключевых встреч.
3. Разложи часы встреч **по направлениям** по названиям (например: продажи, партнёры,
   команда, прочее — по тому, как устроена компания в сводке контекста).
4. Отправь: `./ops notify --kind weekly "<текст>"` — уйдёт в Telegram и в раздел «Дайджесты».

## Формат (Telegram HTML, до 3500 символов)

```
<b>Итоги недели 26.10–01.11</b>
<1–2 строки: главное за неделю>

<b>⏱ Время</b>: 14 встреч, 11,5 ч — продажи 6 ч, партнёры 3 ч, команда 1,5 ч, прочее 1 ч
<b>✅ Закрыто</b>: 9 — главное: …
<b>⚠ Просрочено</b>: 3 — Пётр: … (до 28.10); вы: …
<b>🧭 Решения</b>: … (2–4 самых важных)
<b>🤝 Можно передать</b>: 1–3 ваши задачи, которые логично отдать (кому и почему) — если есть
<b>📅 Следующая неделя</b>: 12 встреч, 10 ч; сроки: …
```

Без Markdown-таблиц и звёздочек. Не выдумывай цифры — только из `./ops week` и того, что открыл.
Задачи называй по названию, без внутренних номеров.

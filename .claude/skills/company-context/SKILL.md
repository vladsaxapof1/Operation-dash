# Сводка «О компании» для Claude

Ты пишешь короткую памятку для самого себя: её получает каждый запуск Claude в PULSE
(вместе с решениями и текущими задачами, которые PULSE добавляет сам). Цель — чтобы без поиска
было понятно, о чём речь: что за компания и продукты, какие направления и кто за них отвечает,
какие проекты идут, что значат внутренние сокращения. Не пересказ документов.

## Шаги

1. **Источники** (по одной команде, без конвейеров):
   - `./ops docs search "карта компании"`, `./ops docs search "главная база знаний"`, `./ops docs search "схема пространства"`,
     `./ops docs search "люди сопоставление"`, `./ops docs search "правила для агентов"` — и прочитай найденные
     `./ops docs show "<файл>"` (длинные — по частям: `--part "фрагмент 1"`);
   - `./ops overview`, `./ops people list`, `./ops kaiten cards --limit 150` — кто что ведёт сейчас;
   - `./ops kb list --days 90` — решения последних месяцев (сами решения в памятку не переписывай: PULSE добавит их отдельно);
   - прошлая версия: Read `data/knowledge/О компании.md` (если есть) — сохрани то, что ещё верно.
2. **Напиши** `data/knowledge/О компании.md` (Write) — не больше 5 000 знаков, разделы:
   - `### Компания и продукты` — 3–6 строк: что продаём, кому, главные продукты и каналы;
   - `### Направления и кто за что отвечает` — список «направление — человек — главная метрика»;
   - `### Проекты в работе` — 5–12 строк «проект — суть — где сейчас»;
   - `### Кто есть кто` — ключевые люди и роли (как их называют в переписке: «Петя», «Маша»);
   - `### Словарь` — сокращения и термины в одну строку каждое (названия отделов, продуктов, метрик…);
   - `### Как работать с данными` — 3–6 главных правил из «Правила для агентов» (полный файл не переписывай).
3. Только факты из источников; не уверен — не пиши. Без внутренних id и путей к файлам, кроме раздела про правила.

Последней строкой ответа — «О компании обновлено: N знаков».

# Дайджест

1. `./ops overview` — всё актуальное одним списком.
2. Для встреч сегодня/завтра посмотри, что открыто с их участниками:
   `./ops commitments list --person "<имя>"` (по 1–2 ключевым участникам, не больше 4 запросов).
3. Составь сообщение и отправь: `./ops notify --kind digest "<текст>"`.

## Утренний

```
<b>Доброе утро! Главное на сегодня</b>
<1–3 строки: самое важное — что горит, что нельзя пропустить>

<b>📅 Встречи</b>
• 10:00 Планёрка — к ней: Олег должен бюджет Q4 (срок вчера)
<b>💬 Ждут вашего ответа</b> (N)
• Ирина: ок по бюджету «Осени» — до 12:00
<b>🫵 Ваши задачи</b> — сегодня/просрочено
<b>🤝 Вам должны</b> — просрочено
<b>🐌 Без движения в Kaiten</b> — 2–3 самых долгих
<b>⏳ Ждут вашего «да»</b>: N — /approvals
```

## Вечерний

```
<b>Итоги дня</b>
• Встречи: что разобрано, главное решение
• Закрыто задач: N; новых: N
<b>Осталось на завтра</b>
• … (ваши задачи со сроком завтра, кто ждёт ответа)
<b>📅 Завтра</b>
• 09:30 …
```

## Правила

- До 3500 символов, в каждом разделе — не больше 5 пунктов, самое важное сверху.
- Пустые разделы пропускай. Если всё спокойно — так и напиши одной строкой.
- Только HTML-теги `<b>`, `<i>`, `<a href>`; без Markdown.
- Имена — как в справочнике, сроки — ДД.ММ или «сегодня/завтра».
- Ничего не создавай и не меняй — дайджест только сообщает.

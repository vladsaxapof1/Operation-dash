# Дайджест

1. `./ops overview` — всё актуальное одним списком. И `./ops day` — реальность дня: утром — сколько времени
   на задачи между встречами, сколько их нужно, вердикт и три главных дела («Строка для дайджеста»); вечером —
   «План дня: сделано N из M» и что не закрыто (перенести его директор может одной кнопкой на Сводке).
2. Для встреч сегодня/завтра посмотри, что открыто с их участниками:
   `./ops commitments list --person "<имя>"` (по 1–2 ключевым участникам, не больше 4 запросов).
3. **Напомнить коллегам** (утром): по задачам «мне должны» со сроком сегодня или уже просроченным —
   `./ops propose remind --commitment <id> --batch digest:<ГГГГ-ММ-ДД>` (текст — по шаблону из настроек,
   свой — `--text "…"`, в тоне переписки с этим человеком). Не больше 5; кому напоминали вчера — не надо.
   Чата с человеком нет — команда скажет; тогда просто упомяни задачу в дайджесте.
4. Составь сообщение и отправь: `./ops notify --kind digest --batch digest:<ГГГГ-ММ-ДД> "<текст>"` — к нему
   приложатся напоминания с кнопками «Да/Нет»: по «Да» сообщение уйдёт человеку от имени директора.
   Дайджест сохранится и в разделе «Дайджесты».

## Утренний

```
<b>Доброе утро! Главное на сегодня</b>
<строка из ./ops day — «Строка для дайджеста» как есть: «Свободно 2 ч 10 мин (тайм-аут 11:00 + 2 окна), задач на
4 ч 30 мин — перегруз. Главное: «…», «…», «…» — разобрать день на Сводке» (со ссылкой)>
<1–2 строки: что ещё горит, что нельзя пропустить>

<b>📅 Встречи</b>
• 10:00 Планёрка — к ней: Олег должен бюджет Q4 (срок вчера)
<b>💬 Ждут вашего ответа</b> (N)
• Ирина: ок по бюджету «Осени» — до 12:00
<b>🫵 Ваши задачи</b> — сегодня/просрочено; «срок под угрозой» — кого ждём
<b>🔓 Можно делать</b> — то, чего задача ждала, готово: «Описание процесса подрядчику» — Дмитрий прислал схемы
<b>📁 Проекты</b> — только где сдвинулось или горит: «Запуск склада — 60%, стоит на Дмитрии (схемы отгрузки)»
<b>🤝 Вам должны</b> — просрочено; «Напомнить» — кнопками ниже
<b>🐌 Без движения в Kaiten</b> — 2–3 самых долгих
<b>⏳ Ждут вашего «да»</b>: N — /approvals
```

## Вечерний

```
<b>Итоги дня</b>
• План дня: сделано N из M — строка из ./ops day (если её нет — плана сегодня не было, пропусти)
• Встречи: что разобрано, главное решение
• Закрыто задач: N; новых: N
<b>Осталось на завтра</b>
• … (ваши задачи со сроком завтра, кто ждёт ответа)
<b>📅 Завтра</b>
• 09:30 …
```

## Правила

- До 3500 символов, в каждом разделе — не больше 5 пунктов, самое важное сверху.
- Пустые разделы пропускай. Если всё спокойно — так и напиши одной строкой.
- Только HTML-теги `<b>`, `<i>`, `<a href>`; без Markdown.
- Имена — как в справочнике, сроки — ДД.ММ или «сегодня/завтра».
- Задача «ждёт» другую (в `./ops overview` — «ждёт [commitment N]») и срок под угрозой — пиши, кого и что ждём:
  «Схемы в карточку проекта — ждёт описания подрядчику, а оно — схем Дмитрия». Раздел «Можно делать» — из `./ops overview`.
- Ничего не создавай и не меняй — дайджест только сообщает.

# PULSE — пульт операционного директора

Личная операционная система директора, которая работает **на её компьютере** —
без серверов, туннелей и облачных сервисов, кроме самого Claude.

PULSE сам собирает рабочую информацию из всех мест, где она живёт:

- **Встречи** (Телемост, Zoom, диктофон) → расшифровка на компьютере с разметкой,
  кто говорит → Claude пишет итог: решения, задачи, обещания, открытые вопросы.
- **Telegram** (ваш аккаунт, только выбранные чаты), **Яндекс Мессенджер**
  (через бота организации), **Яндекс Почта** → Claude отмечает, где ждут вашего
  ответа, и готовит черновик ответа (ищет факты в ваших документах).
- **Kaiten** → видит задачи всех отслеживаемых пространств, напоминает о
  карточках без движения, предлагает новые карточки по итогам встреч и переписки.
- **Яндекс Календарь** → сводка дня, подготовка к встречам, привязка записей.
- **Реестр обещаний** — «что я обещала» и «что мне обещали», со ссылкой на источник.

Управление — через **админку в браузере** (http://localhost:8765) и
**Telegram-бота**: сводки, итоги встреч, кнопки «Да/Нет», вопросы голосом с телефона.
А в Claude Code можно просто спросить: «Что мне обещал Петров на этой неделе?»

Claude **ничего не делает во внешних системах без вашего «Да»**: карточки,
комментарии и встречи сначала попадают в очередь подтверждений.

## Быстрый старт

**Windows 10/11**
1. Установите [Git for Windows](https://git-scm.com/download/win) (все параметры по умолчанию).
2. Скопируйте папку PULSE, например, в `C:\Users\<вы>\Pult` и запустите **INSTALL.bat**.

**macOS 13+ (Apple Silicon и Intel)**
1. Скопируйте папку PULSE в домашнюю папку: `~/Pult` (не в «Документы» и не в iCloud).
2. Запустите **INSTALL.command** (или в Терминале: `cd ~/Pult && bash INSTALL.command`).
   На Apple Silicon расшифровка встреч идёт на видеоядрах — в разы быстрее.

Затем в открывшейся админке пройдите **Настройки** по порядку — подробно в
[docs/02-подключения.md](docs/02-подключения.md).

Посмотреть, как всё выглядит, до подключения источников: в папке PULSE выполните
`.\ops.cmd demo` (Windows, PowerShell) или `./ops demo` (Mac, Терминал);
убрать демо-данные — та же команда с `--clear`.

## Состав папки

```
INSTALL.bat  START.bat  STOP.bat  UPDATE.bat   — установка и управление (Windows)
INSTALL.command  START.command  STOP.command  UPDATE.command — то же для macOS
ops / ops.cmd          — командная строка PULSE (ей пользуется Claude)
CLAUDE.md              — как Claude работает с данными
.claude/skills/        — навыки: разбор встречи, разбор сообщений, дайджест, вопросы
opsdash/               — программа: сборщики, расшифровка, бот, админка
config/                — настройки (settings.yaml)
secrets/               — пароли и токены (создаётся при установке, не передавать!)
data/                  — ваши данные: база, встречи, записи, модели, журнал
docs/                  — документация
```

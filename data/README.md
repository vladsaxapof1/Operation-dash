# data — ваши данные

- `ops.db` — база: сообщения, обещания, задачи, очередь подтверждений;
- `meetings/` — встречи: расшифровки (`transcript.md`) и разборы (`summary.md`);
- `recordings/` — папка для записей (можно класть файлы руками);
- `models/` — модели распознавания речи (скачиваются автоматически);
- `logs/` — журнал работы.

Делайте резервную копию этой папки (и `config`, `secrets`) — см. docs/05-обслуживание.md.

# Передача директору

Для того, кто настраивает PULSE. Установка — [01-установка.md](01-установка.md),
подключения — [02-подключения.md](02-подключения.md), как пользоваться —
[03-как-пользоваться.md](03-как-пользоваться.md).

## Первые две недели

- Через 2–3 дня: спросить, что шумит и что пропускается. Отключить шумные чаты,
  поправить правила важности (их можно дописать в `CLAUDE.md`, раздел «Жёсткие
  правила», или в навык `.claude/skills/triage/SKILL.md`).
- Через неделю: вместе посмотреть «Автономию» — вероятно, разрешить создание
  карточек на неё без подтверждения.
- Убедиться, что делается резервная копия `data`, `config`, `secrets`.
- Новые версии PULSE ставятся кнопкой «Обновить» в настройках — см.
  [05-обслуживание.md](05-обслуживание.md#обновление). Для закрытого репозитория
  оставьте в настройках токен GitHub только на чтение.

## Что важно сказать директору

- PULSE работает, пока включён ноутбук; после сна сам догоняет пропущенное.
- Ничего не создаётся в Kaiten и календаре без её «Да» (пока она сама не разрешит).
- Никому не пишет от её имени — только черновики.
- Папку `secrets` никому не пересылать.

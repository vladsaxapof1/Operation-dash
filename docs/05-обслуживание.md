# Обслуживание

## Обновление

PULSE сам раз в день (и при каждом запуске) проверяет, вышла ли новая версия. Если вышла —
в меню слева появляется «● Доступно обновление».

**Обновить кнопкой:** Настройки → Основное → «Обновления PULSE» → **«Обновить»**. Там же видно,
что изменилось (подробно — в [истории изменений](06-история-изменений.md)), и есть «Проверить обновления». PULSE скачает новую версию, поставит библиотеки
и перезапустится — 1–3 минуты, страница обновится сама. Папки `config`, `secrets` и `data`
не затрагиваются.

**Командой** (в папке PULSE): `./ops update` (Windows: `.\ops.cmd update`); только проверить —
`./ops update --check`. Или **UPDATE.command** / **UPDATE.bat** — то же самое с перезапуском.

**Если в настройках нет «Обновления PULSE»** (Mac, версии до 27.10.2026): откройте **Терминал**
(Программы → Утилиты), вставьте строку и нажмите Enter — PULSE скачает новую версию и перезапустится,
данные и настройки не трогаются:
```
bash -c "$(curl -fsSL https://raw.githubusercontent.com/vladsaxapof1/Operation-dash/claude/pult-v1/scripts/update-old-mac.sh)"
```
Дальше — кнопкой. Присылать для этого файл через Telegram бесполезно: macOS напишет, что он
«повреждён», и не откроет — так она обходится со всеми программами, сохранёнными из Telegram.

**Откуда берётся новая версия** — «Откуда обновлять» в том же блоке: репозиторий GitHub и ветка.
Если репозиторий закрытый, нужен токен только на чтение: GitHub → Settings → Developer settings →
Fine-grained tokens → доступ только к этому репозиторию, право **Contents: Read-only**. Токен
хранится на компьютере директора, в `secrets`.

Папка, установленная через git, обновляется командой `git pull`; из архива — скачиванием архива
ветки поверх папки (файлы, которые из новой версии убрали, удаляются).

Если обновление не удалось (нет связи, токен устарел), PULSE продолжит работать на старой версии,
причина — в «Журнале», задание «Обновление PULSE». Вручную: остановите PULSE (STOP), распакуйте
новый архив **поверх** папки (`config`, `secrets`, `data` не удалять) и запустите UPDATE.

## Резервная копия

Раз в неделю копируйте в надёжное место (лучше в зашифрованный архив):

- `data` — база и встречи (папку `data/models` можно не копировать — скачается заново);
- `config/settings.yaml` — настройки;
- `secrets/.env` — пароли и токены (храните отдельно и надёжно).

Перед копированием `data/ops.db` остановите PULSE (STOP.bat / STOP.command) — так копия
будет целой. На Mac удобно делать это Time Machine — папка PULSE в домашней папке
попадает в копию автоматически.

## Перенос на другой компьютер

1. Установите PULSE на новом компьютере (INSTALL.bat / INSTALL.command).
2. Остановите PULSE на обоих, скопируйте `data`, `config`, `secrets`.
   Переносить можно и между Windows и Mac.
3. Запустите. Сессию Telegram надёжнее создать заново (Настройки → Telegram → Выйти → войти).

## Расход Claude и лимиты подписки

Настройки → Claude → «Расход Claude». Там видно:

- **Лимиты подписки** — на сколько заполнены окно в 5 часов и недельный лимит Pro / Max и когда они
  сбросятся. Claude Code сообщает их при каждом запуске из PULSE; «Обновить» узнаёт заново коротким
  запросом к Haiku. Это лимит всего аккаунта — вместе с вашей работой в приложении Claude и в Claude Code.
  Какую часть занимает PULSE, Claude не сообщает.
- **Сколько стоил бы PULSE по ценам API** — за 7 и 30 дней, прикидка на месяц, столбики по дням и
  таблица «что делал Claude»: разбор встреч, разбор сообщений, брифы, дайджесты, ответы. На подписке
  денег за это не берут, расходуется лимит; цифры пригодятся, если Claude работает по ключу API или
  нужно понять, что съедает лимит. Ориентир: разбор часовой встречи на Opus — около $1, разбор пачки
  сообщений на Sonnet — $0,1–0,3.

Если лимит часто упирается в потолок: поставьте разбор встреч на Sonnet вместо Opus (Настройки →
Claude) — это самая дорогая часть, — или разбирайте сообщения реже (Настройки → Расписание).

## Команды для диагностики

Откройте окно команд в папке PULSE: на Windows — PowerShell (`.\ops.cmd …`),
на Mac — Терминал (`cd ~/Pult`, затем `./ops …`).

| Команда | Что показывает |
|---|---|
| `ops status` | Работает ли PULSE, состояние источников и заданий |
| `ops check` | Проверка всех подключений |
| `ops collect` | Собрать данные сейчас (с выводом ошибок) |
| `ops run triage` | Разобрать новые сообщения сейчас |
| `ops run digest` | Прислать дайджест сейчас |
| `ops daemon` | Запустить PULSE в этом окне (видно все ошибки; перед этим — STOP) |
| `ops mac status` | Mac: установлены ли автозапуск и приложение |
| `ops mac permissions --open` | Mac: какой файл Python добавить в «Полный доступ к диску» |

Журнал: админка → «Журнал», технический — `data/logs/pult.log`
(на Mac ещё `data/logs/launchd.err.log`).

## Частые проблемы

| Проблема | Что делать |
|---|---|
| Админка не открывается | Запустите ярлык/приложение «PULSE» или START.bat / START.command. Не помогло — `ops daemon` покажет ошибку. Порт занят — смените в Настройки → Основное |
| Установка: «не удалось установить uv / библиотеки» | Проверьте интернет. Если в компании прокси — на Windows перед запуском задайте `set HTTPS_PROXY=http://прокси:порт` в окне cmd и запустите INSTALL.bat из него; на Mac — `export HTTPS_PROXY=http://прокси:порт` в Терминале, затем `bash INSTALL.command` |
| Mac: «не удалось проверить разработчика» при запуске .command | Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть», или в Терминале: `cd ~/Pult && bash INSTALL.command` |
| «Claude Code не найден» | Установите (docs/01) и нажмите Настройки → Claude → «Войти в Claude». Или укажите путь в Настройки → Claude |
| Windows: ошибка Claude про Git Bash | Установите Git for Windows (PULSE найдёт его сам, перезапуск не нужен); если стоит не в обычной папке — путь к `bash.exe` в Настройки → Claude |
| Windows: расшифровка падает с ошибкой DLL («DLL load failed») | Нет Microsoft Visual C++ Redistributable — установите https://aka.ms/vs/17/release/vc_redist.x64.exe (нужны права администратора) и запустите INSTALL.bat ещё раз |
| Windows: установщик ругается на OneDrive / рабочий стол | База PULSE не любит синхронизацию: перенесите папку в `C:\Users\<вы>\Pult` и запустите INSTALL.bat оттуда. Ярлыки пересоздадутся |
| Windows: обновление кнопкой, а библиотеки не обновились | На Windows библиотеки обновляются, когда старый PULSE закроется, — журнал в `data\logs\update-libs.log`. Помогает UPDATE.bat |
| Встречи расшифрованы, но не разобраны | Журнал → «Разбор встречи». Чаще всего Claude не вошёл в аккаунт или закончился лимит подписки — повторите позже кнопкой «Разобрать заново» |
| Расшифровка очень медленная | Настройки → Записи встреч → модель `medium`. Не ставьте ноутбук в сон во время расшифровки. На Mac с Apple Silicon проверьте, что выбран движок MLX |
| Расшифровка грузит компьютер, а он сейчас нужен | «Пауза» на странице встречи или в списке встреч — процесс замирает, «Продолжить» — с того же места |
| Записи занимают много места | На странице расшифрованной встречи — «Удалить только запись»: файл удаляется, расшифровка и разбор остаются |
| Модель не скачивается | Сеть блокирует huggingface.co — укажите зеркало в Настройки → Записи встреч |
| Спикеры перепутаны | На странице встречи — «Это я» и «Да, это …» в блоке «Кто в записи», для старых записей «Уточнить спикеров»; если двое сливаются — «чувствительность разметки» 0.8 и «Расшифровать заново» |
| Telegram: «сессия устарела» | Сессию завершили в Telegram → Устройства. Войдите заново в Настройки → Telegram |
| Бот молчит | Настройки → Telegram-бот → «Проверить» и «Отправить проверочное сообщение». PULSE должен быть запущен |
| Почта: «не пустила» | Пароль приложения именно для Почты; включён IMAP; в Яндекс 360 — разрешение администратора |
| Календарь: ошибка входа | Пароль приложения именно «Календарь (CalDAV)»; новый пароль может заработать через 2–3 часа |
| Kaiten: 401 | Токен отозван — создайте новый в профиле Kaiten |
| Kaiten: «нет направлений» | Настройки → Kaiten → «Куда создавать карточки» |
| Я.Мессенджер: нет сообщений | Бот должен быть участником чата; у бота не должен быть настроен вебхук |
| Пачка: «не хватает прав» | Пачка → Интеграции → API → меню токена → «Изменить»: отметьте `chats:read`, `messages:read`, `threads:read`, `users:read` |
| Пачка: «не приняла токен» | Токен удалили или отозвали — создайте новый и вставьте в Настройки → Пачка |
| Дайджест не пришёл | Дайджест приходит только в рабочие дни и в течение 4 часов после заданного времени. `ops run digest` — прислать сейчас |

### macOS: нет доступа к папкам

macOS отдельно охраняет «Документы», «Рабочий стол», «Загрузки» и iCloud Drive.
Обычно при первом обращении PULSE к такой папке появляется окно «…хочет получить
доступ» — нажмите «Разрешить». Если окна не было, а записи Zoom или документы
не находятся (в Журнале ошибка «Operation not permitted»):

1. В Терминале: `cd ~/Pult && ./ops mac permissions --open` — команда покажет путь
   к файлу Python PULSE и откроет «Полный доступ к диску».
2. Нажмите «+», затем Cmd+Shift+G, вставьте показанный путь, «Открыть», включите переключатель.
3. Перезапустите PULSE: STOP.command, затем приложение «PULSE».

Проще всего вообще не давать доступ: в Zoom указать папку записей вне «Документов»
(например, `~/Pult/data/recordings`), а документы держать в синхронизированной папке
Яндекс Диска.

## Удаление

1. Уберите автозапуск: Windows — `powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1`
   (уберёт и ярлык); Mac — `bash scripts/uninstall-mac.sh` (уберёт и приложение).
2. В Telegram → Настройки → Устройства завершите сессию «PULSE».
3. Отзовите пароли приложений (id.yandex.ru) и токен Kaiten.
4. Удалите папку PULSE.

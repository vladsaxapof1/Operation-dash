# PULSE 2.0 — редизайн интерфейса

Спецификация для агента, который переносит новый дизайн в код ветки `claude/pult-v1`.

**Источник истины по виду экранов** — холст с макетами: https://claude.ai/artifact/2oFKM4wo3ofZGSENKzt3Nt
Каждый экран ниже ссылается на свой артборд по имени файла (например, `TasksBoard.dc.html`). Артборды с пометкой «(А)» — целевые. `Main.dc.html`, `Current.dc.html`, `ConceptB/C.dc.html` — история поиска, их **не реализовывать**. `Documents.dc.html` и `KnowledgeBase.dc.html` помечены «в архив, не реализовывать».

Если текст этого файла и макет расходятся — прав макет по виду, этот файл по поведению. Если непонятно — спросить, а не придумывать.

## 0. Границы работы

Меняется: `opsdash/web/templates/*.html`, `opsdash/web/static/style.css`, `opsdash/web/static/dark.css`, `opsdash/web/static/app.js`, небольшие правки в `opsdash/web/app.py` (контекст для шаблонов, новые маршруты-вкладки, флаг архивных разделов).

Не меняется: логика сбора, разбора, расписаний, хранилище, промпты Claude, формат данных в `data/`. Ни одна функция не удаляется — только переезжает или прячется. Исключение — архивные разделы (п. 1.6), но и они выключаются флагом, а не удалением кода.

Демо-данные (`opsdash/demo.py`) должны продолжать отрисовываться на всех экранах без ошибок.

## 1. Принятые решения

1.1. **Характер** — спокойная нейтральная админка. Без новой палитры и шрифтов: та же `system-ui`, тот же индиго-акцент. Работа — в иерархии, плотности и дисциплине меток.

1.2. **Сводка = один поток «Нужно от вас»** (концепция А). Все действия, которые ждут пользователя — подтвердить, ответить, напомнить, объединить дубль — одной лентой с фильтрами по типу. Справа календарь дня и короткий лог «Пока вас не было». Плиток-KPI, блоков «Без движения в Kaiten», «Последние встречи», «Источники», «Лента бота», «Мои задачи», «Мне должны» на Сводке больше нет.

1.3. **«Нужен ответ» растворяется в Сводке.** Пункт меню и экран `/inbox` как очередь ответов уходят. Вместо него раздел **«Переписка»** — окно в читаемые чаты (см. 5.9). Маршрут `/inbox` оставить редиректом на `/chats` (или переименовать маршрут — на усмотрение, но старые ссылки из бота не должны ломаться).

1.4. **«Задачи Kaiten» — вкладка внутри «Задач»**, а не пункт меню. Вкладки «Задач»: Доска · Список · Гант · Проекты · Kaiten.

1.5. **Меню сгруппировано**, 12 пунктов вместо 15 (см. 4).

1.6. **Документы и База знаний — архивные разделы.** Нет в меню, страницы не открываются (редирект на Настройки → Архивные разделы), их фоновые задания (индекс документов, обзор базы знаний, сводка «О компании») не запускаются, агент «Архивариус» в Офисе помечен «в архиве». Данные в `data/` не трогаются. Включить обратно — Настройки → Архивные разделы → «Включить»; после перезапуска раздел, его задания и агент возвращаются. Хранить флаг в `config/settings.yaml`, например `sections: {docs: archived, kb: archived}`; по умолчанию в 2.0 — `archived`.

1.7. **Дайджесты остаются** отдельным разделом.

1.8. **Календарь без строки «сроки задач».** Только встречи.

1.9. **Карточка задачи и карточка человека — диалоги поверх списка**, не отдельные страницы.

Правило смысла цвета (обязательное):

- **Синий** — только то, что кликается или выбрано: ссылка, основная кнопка, активный пункт/вкладка, «сейчас».
- **Красный** — только просрочка и необратимое действие (удалить, отменить задачу).
- **Оранжевый** — только «скоро/застой/внимание»: завтра, без движения, дубль, ждёт вас.
- **Зелёный** — только состояние «сделано/подключено». Зелёных кнопок нет совсем (старые зелёные «Да» и «Ответила» — уже не зелёные, см. 3.1).
- Цифры-счётчики по умолчанию нейтральные. Цвет у цифры — только если она про просрочку или застой.

### 2.2. Текст

Шрифт — `var(--font)` без изменений. Шкала (убрать 12.5 / 13.5 / 14.5 и прочие промежуточные):

| Роль | Размер / высота строки | Жирность |
|---|---|---|
| Заголовок страницы `h1` | 26 / 1.25 | 600 |
| Заголовок диалога | 20 / 1.3 | 600 |
| Заголовок карточки/секции `h2` | 18 (в узких колонках 16) | 600 |
| Название задачи на карточке | 15 / 1.35 | 600 |
| Основной текст | **16 / 1.5** (было 14–15) | 400 |
| Вторичный текст, строки метаданных | 14 | 400 |
| Мелкий: время, мета, подписи полей | 13 | 400 |
| Минимум: метки осей, тайм-коды | 12 (в Ганте 11) | 400 |
| Подпись группы (ЗАГЛАВНЫМИ) | 12–13, `letter-spacing: .04em`, `--muted` | 600 |

Жирность 600 — **только** заголовки и названия задач/встреч в списках. Имена людей, кнопки, чипы, значения в таблицах — 400. Сейчас жирно почти всё; это главная причина «каши».

### 2.3. Радиусы, тени, отступы

- Радиусы: карточка/таблица/панель **12**, колонка доски **12**, карточка задачи **8**, кнопка/поле **8**, мелкая кнопка **6**, диалог **14**, чип/счётчик **999**.
- Тень: карточки — **нет** (только рамка `--line`). Карточка задачи на доске — `0 1px 2px rgba(28,34,48,.06)` без рамки. Раскрытая/выбранная карточка — кольцо `0 0 0 2px var(--accent)` + `0 4px 12px rgba(28,34,48,.12)`. Диалог — `0 20px 60px rgba(28,34,48,.28)`, подложка `rgba(28,34,48,.42)`. Выпадающее меню — `0 8px 24px rgba(28,34,48,.16)`.
- Правило: **либо рамка, либо тень**, не обе.
- Отступы страницы: `28px 36px 48px`. Между блоками страницы 20–24. Внутри карточки 18–24 по горизонтали. Строка списка — 12–14 по вертикали, разделитель сверху `1px --line`.
- Максимальная ширина контента обычных страниц — 1120px; доска, Гант, календарь — во всю ширину.

## 3. Компоненты

### 3.1. Кнопки

Три вида, других нет:

| Вид | Стиль | Когда |
|---|---|---|
| Основная | фон `--accent`, белый текст, без рамки | одно главное действие в зоне: «Да», «+ Задача», «Отправить», «Загрузить запись», «Ответить» у срочного |
| Контурная | фон `--panel`, рамка `--line-strong`, текст `--text` | все остальные действия: «Нет», «В работе», «Разобрать», «Напомнить», «Копировать» |
| Текстовая | без фона и рамки, `--muted` | «Скрыть», «Это не дубль», «Не нужно» |

Высоты: 38–40 (шапка страницы), 34–36 (в карточке), 30–32 (в строке списка), 28 (иконка-кнопка на карточке). «Готово» — контурная с зелёной галочкой и зелёным текстом (`--ok-text`), не зелёная заливка.

Правила:

- **Действие над элементом в строке списка — всегда контурная кнопка**, не ссылка-текст. Ссылка-текст — только переход «куда-то»: «все →», «на доске →», «открыть в Kaiten ↗», источник.
- На карточке/в строке **не больше двух видимых кнопок и одного меню «…»**. Всё, что делается редко (изменить, в архив, отменить, удалить, переименовать, разобрать заново, назначить встречу, передать), — в «…».
- Иконка-кнопка без текста — обязательно `aria-label` и `title`.

### 3.2. Ссылки

Любое упоминание задачи, встречи, человека, проекта, чата, карточки Kaiten, по которому можно перейти, — синяя ссылка `--accent`. Без исключений (в списках задач из встречи, в «Стоит на», в предложениях «да», в ответах Claude, в дайджестах). Название без перехода — `--text`.

### 3.3. Карточка-контейнер

`--panel`, рамка `1px --line`, радиус 12, без тени. Заголовок секции 16–18/600, справа от него опционально «все →» (текстовая ссылка 14) и серый счётчик. Внутри — строки с разделителем сверху.

### 3.4. Колонка доски

Фон `--sunken`, радиус 12, padding 10, gap 8 между карточками. Шапка колонки в одну строку без переноса: название 15/600 · серое количество · **кружок-счётчик** просрочек (красный, `--bad-text`, белая цифра 12/600, мин. ширина 20) или застоя (оранжевый `--warn-fill`) · справа «+» (иконка-кнопка). Подпись под шапкой (13, `--muted`) — только если колонка не очевидна («ничего не ждут», «ждут задач слева»).

### 3.5. Карточка задачи на доске

**Компактная (по умолчанию) — ровно две строки:**

1. Название, 15/600, переносится.
2. Мета 13 `--muted`: `человек · срок` и, если есть, иконка часов (ждёт другую задачу), «3 из 6», «дубль?».

Убрать с карточки совсем: чип «новая», «от 01.11», чип проекта, источник, блоки «ЖДЁТ / ЕЁ ЖДУТ» в рамке, кнопки «В работе / Готово / отправить / карандаш».

Просроченная — левая кромка `3px --bad-text`. Больше никаких цветных рамок у карточек.

**Раскрытая (клик по карточке, раскрывается на месте, второй клик сворачивает):** + одна строка про зависимость («ждёт график от Дмитрия, *просрочен*»), + ряд из трёх иконок-кнопок 28×28 (готово ✓, в работе ▶, напомнить 🔔 — только у долгов) и справа ссылка «открыть» 13. Источник и проект в раскрытой карточке **не показывать** — они в диалоге.

**Диалог задачи** — см. 5.4.

### 3.6. Даты

- Относительная дата, когда срок близко или прошёл: «сегодня», «завтра», «просрочено 2 дня». **Не дублировать** числом («02.11, завтра» → «завтра»).
- Абсолютная дата `ДД.ММ`, когда срок дальше недели или в таблицах.
- В заголовке/мете диалога можно оба: «завтра, 02.11».
- Цвет даты: просрочено — `--bad-text`, сегодня/завтра — `--warn-text`, иначе `--muted`.

### 3.7. Чипы и метки

Чип-пилюля остаётся только для: фильтра-переключателя (Все · 8 / Подтвердить · 4…), активного фильтра со «×», контекста в «Спросить Claude», «срочно» в ленте. Статусы задач/встреч — **текстом с цветной точкой 8px** («● разобрана»), не пилюлей.

### 3.8. Таблицы

Без фиксированного `min-width` — ячейки переносятся. Первая колонка — 22–32% ширины. Заголовки 13/600 `--muted`. Строки-группы (`th scope="rowgroup"`) — 14/600 `--muted`. Широкое содержимое (Гант) — в контейнере `overflow-x: auto`, страница вбок не скроллится.

### 3.9. Сегментированный переключатель

Вкладки видов («Доска · Список · Гант…», «Неделя · Месяц», тема, ОС в справке): рамка `--line-strong`, радиус 8, активный — фон `--accent-soft`, текст `--accent`, 600.

### 3.10. Подменю второго уровня (Настройки, Справка)

Колонка 220px слева. **Без подписей групп.** Пункт верхнего уровня 15, padding 8×10. Вложенные пункты — сдвиг 14px, левая направляющая `2px --line` (у активного — `--accent`), 14px, padding 5×10×5×14. Разделитель `1px --line` перед системными пунктами.

### 3.11. Диалог

Ширина 680–720, радиус 14, padding 24/28. Шапка: заголовок 20/600 (+ карандаш `--faint` для переименования) · справа селект статуса или кнопка «Спросить Claude» · «×». Под заголовком **одна** строка меты 14 `--muted` через « · ». Блоки внутри — секции с подписью ЗАГЛАВНЫМИ или панели `--panel-2` (карточка человека). Низ: основная + контурная + «Спросить Claude» слева, «…» справа. Последняя строка 13 `--muted` — происхождение («появилась 01.11 из планёрки, 00:14:02 · история изменений»).

### 3.12. Пустые состояния

Одна фраза + одно действие. Нулевые KPI-плитки на пустом разделе не показывать. Баннеры-подсказки закрываемые (×) и запоминают закрытие.

### 3.13. Поля

Высота 38–40, рамка `--line-strong`, радиус 8. Метка над полем 14/600, подсказка под полем 13 `--muted`. У `type="time"` — `lang="ru"` (сейчас показывает AM/PM). Нативный «Choose File» заменить зоной перетаскивания с пунктирной рамкой.

## 5. Экраны

Для каждого: маршрут / шаблон → артборд → структура → что убрать.

### 5.1. Сводка — `/` · `home.html` → `ConceptA.dc.html`

Строка: круглая иконка типа 36px слева (красная для срочного/просроченного, синяя для остальных) · строка типа 14 («Ответить · срочно, до завтра 12:00») · название 16/600 · одна строка контекста 14 `--muted` (источник, время, черновик в кавычках) · справа одна кнопка (основная у срочных, контурная у остальных) + «…». ## 6. Порядок внедрения

Каждый шаг — отдельный коммит, после каждого все экраны открываются на демо-данных.

1. **Токены и база.** Новые переменные в `style.css`/`dark.css` (2.1), шкала текста (2.2), радиусы/тени (2.3). Привести `.btn`, `.card`, чипы, таблицы, поля к разделу 3. Убрать лишний `font-weight` по всему CSS.
2. **Навигация.** Меню по 4.1–4.3 в `base.html`; счётчики; свёрнутый режим; нижняя панель на узких.
3. **Архивные разделы.** Флаг в настройках, скрытие пунктов, редиректы `/docs` и `/kb`, отключение их заданий в планировщике, страница «Архивные разделы».
4. **Задачи:** карточка (3.5) и диалог (5.4) — это основа для Сводки, проектов и встреч. Затем доска, список, Гант, проекты, Kaiten-вкладка (+ редирект `/tasks`).
5. **Сводка** (5.1) — использует ленту из «Нужно от вас» и компоненты задач.
6. **Встречи и встреча** (5.9, 5.10).
7. **Переписка** (5.11) + редирект `/inbox`.
8. **Календарь** (5.8).
9. **Люди** + диалог (5.13).
10. **Дайджесты, Спросить Claude, Офис, Журнал** (5.12, 5.14–5.16).
11. **Настройки и Справка** (5.17, 5.18).
12. Проход по тёмной теме и узкому экрану на всех экранах.

## 7. Приёмка

- [ ] На каждом экране не больше одной основной (синей) кнопки в зоне.
- [ ] Нет зелёных кнопок. Зелёный — только текст/точка «сделано/есть».
- [ ] Нет чипа «новая» и «от ДД.ММ» нигде.
- [ ] Компактная карточка задачи — ровно две строки.
- [ ] Любая упомянутая задача/встреча/человек — синяя ссылка.
- [ ] Действия в строках списков — контурные кнопки, не текст.
- [ ] Даты: «завтра» не дублируется числом.
- [ ] Цепочка зависимостей видна через все колонки.
- [ ] В меню 12 пунктов, Документов и Базы знаний нет; `/docs`, `/kb`, `/tasks`, `/inbox` не отдают 404.
- [ ] Архивные разделы включаются обратно из Настроек и возвращают пункт меню, задания и агента.
- [ ] `type="time"` без AM/PM.
- [ ] Ни одна таблица не скроллит страницу вбок на 1280px.
- [ ] Тёмная тема: карточки отделены от фона, мелкий серый текст читается.
- [ ] Мелкий текст ≥ 12px, контраст ≥ 4.5:1 (проверять `--muted` на `--bg` и `--panel-2`).
- [ ] Демо-данные (`opsdash/demo.py`) отрисовываются на всех экранах.

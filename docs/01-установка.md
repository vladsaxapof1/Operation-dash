# Установка

PULSE ставится на рабочий ноутбук директора — **Windows 10/11** или **macOS 13+**
(Apple Silicon и Intel). Права администратора не нужны: всё устанавливается в профиль
пользователя. Займёт 20–40 минут, большая часть — ожидание загрузок.

## Что понадобится

| Что | Зачем | Где взять |
|---|---|---|
| Windows 10/11 или macOS 13 Ventura+, 8 ГБ памяти (лучше 16), 5 ГБ на диске | Расшифровка встреч идёт на этом компьютере | — |
| Интернет | Установка, модели распознавания речи, Claude | — |
| Только Windows: Git for Windows | Claude Code на Windows работает через Git Bash | https://git-scm.com/download/win |
| Аккаунт Claude с доступом к Claude Code | «Мозг» PULSE | Подписка Max или место в Team с Claude Code (уточните у администратора команды) |
| Папка PULSE | Сама программа | От того, кто настраивает |

## Windows

### Шаг 1. Git for Windows

Скачайте установщик с https://git-scm.com/download/win и установите со всеми
параметрами по умолчанию.

### Шаг 2. Папка PULSE

Скопируйте папку PULSE в профиль, **не на рабочий стол и не в OneDrive**, например:
`C:\Users\<вы>\Pult`. В пути лучше избегать пробелов.

### Шаг 3. INSTALL.bat

Дважды щёлкните **INSTALL.bat**. Скрипт:

1. установит `uv` — менеджер Python (Python ставится внутрь папки PULSE и не
   мешает другим программам);
2. скачает библиотеки (первый раз — 3–10 минут);
3. создаст настройки `config\settings.yaml` и закроет доступ к папке `secrets`
   для других пользователей компьютера;
4. проверит Git и Claude Code; если Claude Code нет — предложит установить;
5. создаст ярлык **«PULSE»** на рабочем столе и добавит PULSE в автозапуск;
6. запустит PULSE и откроет http://localhost:8765.

Если Windows SmartScreen спросит про запуск .bat — «Подробнее» → «Выполнить в любом случае».

### Шаг 4. Вход в Claude Code (один раз)

Откройте **PowerShell** (Пуск → PowerShell) и выполните `claude`. Выберите вход через
аккаунт Claude.ai и войдите в браузере. После входа окно можно закрыть — PULSE будет
запускать Claude сам. Проверка: админка → Настройки → Claude → «Проверить подключение».

Если команды `claude` нет — установите Claude Code в PowerShell:
`irm https://claude.ai/install.ps1 | iex` — и откройте новое окно PowerShell.

## macOS

### Шаг 1. Папка PULSE

Скопируйте папку PULSE прямо в домашнюю папку: `/Users/<вы>/Pult` (в Finder:
Переход → Домой). **Не кладите её в «Документы», на «Рабочий стол», в «Загрузки» и
в iCloud Drive** — macOS защищает эти места отдельно, а iCloud может выгрузить базу
с диска.

### Шаг 2. INSTALL.command

Дважды щёлкните **INSTALL.command**. Если macOS ответит «не удалось проверить
разработчика» — это из-за того, что папка скачана из интернета. Два способа:

- Системные настройки → Конфиденциальность и безопасность → внизу «INSTALL.command
  заблокирован» → «Всё равно открыть»; или
- откройте **Терминал** (Программы → Утилиты) и выполните:
  ```
  cd ~/Pult && bash INSTALL.command
  ```

Установщик:

1. снимет с папки пометку «скачано из интернета» (дальше всё запускается без вопросов);
2. установит `uv` и Python внутрь папки PULSE, скачает библиотеки (3–10 минут).
   На Apple Silicon с macOS 14+ дополнительно включит **ускоренную расшифровку на
   видеоядрах (MLX)** — час записи разбирается за несколько минут;
3. создаст настройки и закроет папку `secrets` от других пользователей;
4. проверит Claude Code; если его нет — предложит установить;
5. добавит PULSE в автозапуск (служба macOS, перезапускается после сбоя) и создаст
   приложение **«PULSE»** в папке «Программы» — его удобно перетащить в Dock.
   Если macOS не даёт писать в общую папку «Программы» (учётная запись без прав
   администратора), приложение окажется в личной: Finder → Cmd+Shift+G → `~/Applications`;
6. покажет, к каким папкам PULSE нужен доступ, и откроет http://localhost:8765.

### Шаг 3. Вход в Claude Code (один раз)

Откройте админку → Настройки → Claude. Если на Mac стоит приложение Claude, PULSE сам найдёт
Claude Code, который скачало приложение. Нажмите **«Войти в Claude»**: откроется Терминал,
а за ним браузер — войдите аккаунтом Claude.ai и обновите страницу настроек.

Если Claude Code не найден — установите его в **Терминале**:
`curl -fsSL https://claude.ai/install.sh | bash`, затем выполните `claude` и войдите в браузере.
Проверка: Настройки → Claude → «Проверить подключение».

### Шаг 4. Разрешения macOS

Если папка записей Zoom или папки с документами лежат в «Документах» / на «Рабочем
столе» / в iCloud, при первом обращении macOS покажет окно «python3 хочет получить
доступ к папке…» — нажмите **«Разрешить»**. Если окно не появилось, а файлы не
находятся — см. [05-обслуживание.md](05-обслуживание.md#macos-нет-доступа-к-папкам).

## Как запускать и останавливать

| Действие | Windows | macOS |
|---|---|---|
| Открыть PULSE | Ярлык «PULSE» на рабочем столе (или START.bat) | Приложение «PULSE» (или START.command) |
| PULSE запускается сам | При входе в Windows | При входе в macOS |
| Остановить | STOP.bat | STOP.command |
| Обновить | UPDATE.bat | UPDATE.command |
| Убрать автозапуск | `powershell -ExecutionPolicy Bypass -File scripts\uninstall.ps1` | `bash scripts/uninstall-mac.sh` |

Подробнее об обновлении — [05-обслуживание.md](05-обслуживание.md).

PULSE работает, пока включён компьютер. Если ноутбук был выключен или спал, PULSE
после включения сам догонит пропущенное: соберёт сообщения, пришлёт дайджест.

## Работа с Claude в чате

Откройте папку PULSE в Claude Code — так директор задаёт вопросы своим данным:

- **Приложение Claude для компьютера** → вкладка Code → выбрать папку PULSE; или
- **PowerShell / Терминал**: перейти в папку PULSE (`cd C:\Users\<вы>\Pult` или
  `cd ~/Pult`), затем `claude`.

Примеры вопросов — в [03-как-пользоваться.md](03-как-пользоваться.md).

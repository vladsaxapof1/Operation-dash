# Как устроено

## Схема

```
 Источники                 Сборщики (без ИИ)            Хранилище data/              Claude (навыки)            Выход
 ─────────                 ─────────────────            ───────────────              ───────────────            ─────
 Telegram (аккаунт) ──┐                                 ops.db:                      process-meeting            Kaiten
 Пачка (токен)      ──┤
 Я.Мессенджер (бот) ──┤                                  сообщения, чаты               (разбор встречи)          (после «Да»)
 Я.Почта (IMAP)     ──┼─► PULSE: сбор по расписанию ─►   календарь, Kaiten     ◄──►  triage                     Telegram-бот
 Я.Календарь (CalDAV)─┤                                  люди, обещания,               (разбор сообщений)        Админка
 Kaiten (API)       ──┘                                  «нужен ответ»,              digest (дайджесты)         Claude Code
                                                         очередь подтверждений        ask (вопросы из бота)      (чат директора)
 Записи встреч ─────────► Whisper + разметка   ────►   meetings/<id>/
 (папки, бот, загрузка)    спикеров (локально)           transcript.md, summary.md
```

**Принцип:** сборщики — простые программы без ИИ, они только забирают новое.
Всё, что требует понимания (что важно, кто что обещал, какую задачу поставить),
делает Claude по навыкам из `.claude/skills/`. Связь Claude с данными — команда
`./ops` (описана в `CLAUDE.md`).

## Один процесс — «PULSE»

`python -m opsdash daemon` (запускается ярлыком без окна) — это:

- **админка** на http://localhost:8765 (только этот компьютер);
- **планировщик** с пятью очередями: лёгкой (сбор данных), тяжёлой (плановые запуски Claude),
  расшифровки, вопросов из Telegram и чата «Спросить Claude» — чтобы часовая расшифровка,
  расшифровка на паузе или подробный разбор в чате не задерживали ни сбор сообщений, ни дайджесты,
  ни ответы;
- **Telegram-бот** — сам спрашивает Telegram о новых сообщениях (long polling), поэтому
  не нужны ни сервер, ни туннель, ни «белый» IP.

Автозапуск: на Windows — ярлык в «Автозагрузке» (запуск без окна через `pythonw`),
на Mac — служба launchd (`~/Library/LaunchAgents/local.pult.director.plist`),
которая поднимает PULSE при входе и перезапускает после сбоя. Второй экземпляр
не запустится: PULSE держит блокировку `data/pult.lock`.

Расшифровка: на Windows и Intel-маках — faster-whisper на процессоре; на Apple Silicon
(macOS 14+) — MLX на видеоядрах, при любой ошибке MLX PULSE сам переходит на faster-whisper.

Если PULSE выключить, ничего не теряется: при следующем запуске сборщики
продолжат с того места, где остановились, а прерванные расшифровки начнутся заново.
Расшифровка, поставленная на паузу, после перезапуска ждёт кнопки «Продолжить» и тогда
начинается сначала: пауза замораживает процесс расшифровки, и его прогресс живёт, пока работает PULSE.

## Расписание по умолчанию

| Задание | Когда |
|---|---|
| Сбор Telegram, Пачки, Я.Мессенджера, почты | каждые 15 мин |
| Обновление Kaiten и календаря | каждые 30 мин |
| Поиск новых записей | каждую минуту |
| Разбор сообщений (Claude, sonnet) | каждые 2 часа в рабочее время, если есть новые, — или сразу, как накопится 50 новых (не чаще раза в 10 минут; число — в Настройки → Расписание) |
| Разбор встречи (Claude, opus) | сразу после расшифровки |
| Утренний / вечерний дайджест | 09:00 / 18:30, рабочие дни |
| Напоминание о задачах без движения | 10:00, рабочие дни |

Всё меняется в Настройки → Расписание.

## Данные

| Где | Что |
|---|---|
| `data/ops.db` | SQLite: сообщения, чаты, календарь, зеркало Kaiten, люди, обещания, «нужен ответ», предложения, журнал |
| `data/chats/<id>/` | файлы, приложенные к вопросам в «Спросить Claude», и их текст (`.md` рядом с презентацией, таблицей, Word, PDF) |
| `data/meetings/<дата>_<название>/` | `transcript.md` (расшифровка), `transcript.json` (реплики с временем), `meta.json` (встреча календаря), `summary.md` (разбор Claude) |
| `data/recordings/` | Папка для записей по умолчанию (+ загруженные и присланные боту) |
| `data/models/` | Модели Whisper и разметки спикеров |
| `data/logs/pult.log` | Технический журнал |
| `config/settings.yaml` | Настройки (без паролей) |
| `secrets/.env` | Пароли приложений, токены, сессия Telegram |

## Что может и чего не может Claude

| Может | Не может |
|---|---|
| Читать базу PULSE, встречи, папки с документами | Читать `secrets/`, менять настройки и код |
| Писать разборы встреч и заметки в `data/` | Запускать любые команды, кроме `./ops` |
| Вести обещания, «нужен ответ», справочник людей | Создавать карточки и встречи без «Да» (если не разрешено в «Автономии») |
| Предлагать карточки, комментарии, встречи | Писать коллегам от имени директора |
| Писать директору в бот | Выходить в интернет в фоновых запусках |

Ограничения заданы дважды: правилами в `CLAUDE.md` и разрешениями Claude Code
(`.claude/settings.json` и параметры фонового запуска в `opsdash/brain.py`).

## Безопасность

- Админка слушает только `127.0.0.1`; запросы с других сайтов отклоняются (проверка Host/Origin).
- Пароли и сессия Telegram — в `secrets/.env`, доступ к папке — только у пользователя Windows.
- Звук и расшифровка встреч не покидают компьютер. В Claude уходят тексты, которые
  он разбирает (расшифровки, сообщения выбранных чатов) — в рамках подписки Claude.
- Бот отвечает только привязанному по коду аккаунту.
- Почта читается без отметки «прочитано»; Telegram — только выбранные чаты.

## Модули программы

| Файл | Что делает |
|---|---|
| `opsdash/daemon.py` | Запуск PULSE: веб + планировщик + бот |
| `opsdash/jobs.py` | Задания и расписание |
| `opsdash/sources/*.py` | Сборщики: telegram, pachca, ymessenger, mail, calendar, kaiten |
| `opsdash/recordings.py`, `transcribe.py` | Папки записей, Whisper, разметка спикеров, импорт текстов |
| `opsdash/brain.py` | Запуск Claude Code в фоне (`claude -p`) |
| `opsdash/proposals.py` | Очередь подтверждений и выполнение действий |
| `opsdash/bot.py` | Telegram-бот |
| `opsdash/records.py`, `overview.py` | Люди, обещания, встречи, сводки |
| `opsdash/cli.py` | Команда `ops` |
| `opsdash/macos.py` | macOS: служба автозапуска, приложение, права доступа |
| `opsdash/web/` | Админка (FastAPI + шаблоны) |
